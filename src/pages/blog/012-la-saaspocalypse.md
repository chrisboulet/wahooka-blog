Quelque chose s'est passé tranquillement sous le buzz IA du début 2026 : environ 285 milliards de dollars en capitalisation boursière SaaS ont disparu. Pas parce que les produits ont cassé. Parce que les investisseurs ont fait du maths.

Le maths : si un agent autonome fait ce qu'un SaaS à 50$/siège fait, pour trois cents la tâche — pourquoi le SaaS à 50$/siège existe encore?

Bonne question. La réponse est plus intéressante que "y'en a plus besoin."

**Pas tous les logiciels sont égaux face aux agents.**

Y'a une distinction que je reviens sans arrêt : le travail *déterministe* vs le travail *probabiliste*.

Le logiciel déterministe fait la même chose à chaque fois. Entrée A, sortie B. Toujours. Les ERP, les moteurs comptables, les pipelines de conformité — déterministes par design. Légal, auditable, zéro tolérance pour la variance. Les agents sont peureux en travail déterministe. Ils sont créatifs, ce qui est un problème quand "créatif" veut dire "des fois la facture a une coquille."

Le travail probabiliste, c'est différent. Décisions CRM. Routage de support. Rédaction de contenu. Priorisation. Des jugements dont la "bonne" réponse change selon le contexte, le ton, ce qui s'est passé la veille. C'est exactement là que les agents excellent — et où le SaaS horizontal générique est en danger réel.

Gartner projette que plus de 40% des applications enterprise vont intégrer des agents autonomes d'ici la fin 2026. Une hausse de 800% vs 2025. Pas "des fonctionnalités IA rajoutées après coup." Une architecture agent-first qui remplace ce qu'un SaaS faisait avant.

**Le portrait pratique.**

J'opère une machine de 40+ agents. Voici ce qui a été remplacé : recherche préliminaire, rédaction de drafts, qualification de pipeline, monitoring quotidien, tout ce qui nécessitait autrefois quelqu'un pour *juste garder un œil sur les affaires*.

Ce qui n'a pas été remplacé : la couche comptable, la structure CRM (la base de données, pas le jugement), le stockage de documents. Infrastructure déterministe.

Le pattern de remplacement c'est pas "vire ton SaaS." C'est : partout où y'avait quelqu'un qui faisait quelque chose de routinier, qui révisait quelque chose de formulaïque, ou qui décidait quelque chose à l'instinct — c'est le territoire des agents maintenant.

**La SaaSpoCalypse est réelle. Elle est juste sélective.**

Les SaaS horizontaux génériques bâtis pour des workflows probabilistes — CRM léger, outils de support, plateformes de contenu — regardent leurs valuations compresser pour une bonne raison.

L'infrastructure déterministe — moteurs comptables, bases de conformité, backbones ERP — c'est correct. Pour l'instant.

La question intéressante : qu'est-ce qui arrive quand la ligne se brouille? Quand les agents deviennent assez fiables pour les données financières? Quand la "comptabilité créative" arrête d'être une joke et devient un risque de déploiement?

Ce jour-là, c'est pas aujourd'hui. Mais le marché est déjà en train de pricer la possibilité.
